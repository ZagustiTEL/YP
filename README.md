# YP
# Приложение для изучения языков

GUI-приложение для изучения иностранных языков с использованием базы данных SQLite.

## Возможности

### 📚 Управление языками
- Добавление новых языков для изучения
- Указание уровня владения (beginner, intermediate, advanced)
- Просмотр списка всех изучаемых языков

### 📝 Управление словарем
- Добавление слов с переводом, категорией и сложностью
- Отметка слов как выученных
- Фильтрация слов по языкам
- Удаление слов из словаря

### 🎯 Режим изучения
- Интерактивные сессии изучения слов
- Постепенное изучение невыученных слов
- Возможность просмотра перевода
- Отметка слов как выученных прямо во время изучения

### 📊 Отслеживание прогресса
- Статистика по каждому языку
- Общий прогресс изучения
- Количество выученных и всех слов
- Визуализация прогресса в процентах

## Установка и запуск

### Требования
- Python 3.6+
- Библиотека tkinter (обычно входит в стандартную поставку Python)

### Запуск приложения
1. Убедитесь, что все файлы находятся в одной папке:
   - `app.py` - основной файл приложения
   - `database.py` - модуль работы с базой данных
   - `language_learning.db` - база данных (создается автоматически)
