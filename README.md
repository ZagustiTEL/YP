# YP
# Программа для изучения языков

Простое консольное приложение для изучения английского и испанского языков.

## Возможности

- **Тренировка перевода** - угадайте перевод слова с иностранного на русский
- **Тренировка написания** - напишите слово на иностранном языке по переводу
- **Просмотр словаря** - отображение всех слов и их переводов
- **Добавление слов** - возможность расширять словарь новыми словами

## Поддерживаемые языки

- Английский (english)
- Испанский (spanish)
